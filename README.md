# portfolio
Affiliate Platform API — Backend Project Develop for backend practices with Node.js, TypeScript, Fastify, GraphQL, Apollo Server, PostgreSQL, Prisma, REST, OpenAPI/Swagger. Developed REST CRUD APIs and GraphQL queries integrated with PostgreSQL through Prisma. Implemented API documentation and testing using Swagger/OpenAPI.

I developed a mini affiliate platform focused on practicing backend development.

I used Node.js and TypeScript, along with Fastify to build a REST API and PostgreSQL as the database, accessed via the Prisma ORM.

In the REST API, I implemented product CRUD operations: GET, POST, PUT, and DELETE, and used Swagger/OpenAPI to document and test the endpoints.

I then added a second layer of access to the same data using GraphQL with Apollo Server, allowing products to be queried.

The current architecture is:

REST, Fastify, Prisma, PostgreSQL, GraphQL, Apollo Server, Prisma, PostgreSQL

The main goal of the project was to gain practical insight into how a backend application communicates with a database and how different API interfaces can work with the same data.
